# Modul IPS Kelas 7 — Bab I (Diri dan Keluarga)

Situs statis hasil konversi dari *Modul_IPS_MTs_Kelas_7_Transkrip.docx* (LP. Ma'arif NU Kab. Jepara), dipecah per bagian dengan ringkasan di awal tiap bagian.

## Struktur halaman
- `index.html` — Sampul, daftar isi, capaian pembelajaran, dan ringkasan Bab I
- `bagian-a.html` — A. Diri dan Keluarga (+ ringkasan bagian, assesmen diagnostik, aktivitas 1)
- `bagian-b.html` — B. Kedudukan Diri dan Keluarga / Silsilah (+ ringkasan bagian, assesmen diagnostik, aktivitas 2)
- `bagian-c.html` — C. Mengenal Lokasi Tempat Tinggal / Kondisi Wilayah Jepara (+ ringkasan bagian, aktivitas 3–4, lampiran desa)
- `bagian-d.html` — D. Menemukan Lokasi dengan Peta (+ ringkasan bagian)
- `asesmen-bab1.html` — Asesmen Formatif Akhir Bab I & Asesmen Sumatif Tengah Semester
- `style.css` — Gaya bersama seluruh halaman

## Cara publish ke GitHub Pages
1. Push seluruh isi folder ini ke repository GitHub (misalnya `modul-ips-kelas7`).
2. Buka **Settings → Pages**.
3. Pilih source: `Deploy from a branch`, branch `main`, folder `/root`.
4. Situs akan tersedia di `https://<username>.github.io/<nama-repo>/`.

## Catatan sumber
Naskah ini adalah transkripsi dari foto halaman 9–28 modul cetak (halaman 14 dan 18 tidak tersedia di sumber). Gambar/peta/diagram digambarkan secara tekstual pada kotak 🖼️ karena tidak dapat direproduksi persis seperti aslinya.
